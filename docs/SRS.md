# Software Requirements Specification
## ClassConnect GH

### Problem Statement
Manual attendance wastes 5-10 mins per class. LMS doesn't aggregate grades or provide insights. Students don't know if at risk. No early warning system. Department lacks cohort analytics.

### Core Features
1. Attendance Tracking (QR/PIN)
2. Grade Aggregation
3. Predictive Analytics (early warning)
4. Academic Standing (probation tracking)
5. Department Reports

### User Roles
- Student: View attendance %, grades, GPA, alerts
- Lecturer: Mark attendance, input grades, view class performance
- Admin: Monitor standing, generate reports

### Use Cases
1. Student views attendance percentage
2. Lecturer marks attendance via QR/PIN
3. Student gets early warning if grades drop
4. Admin generates cohort report
5. Lecturer views class analytics
